# setup-cookbook

> 按操作系统整理的开发与日常工具清单。内容由社区维护，工具失效了欢迎提 Issue 或 PR。
>
> 起因是复现 [microduck](https://github.com/fanhao375/microduck-replica) 时，开发机是 Mac，教程用的却是 Windows 上的烧录软件，只好另找替代品（balenaEtcher）。这类「换个系统就找不到对应工具」的问题很常见，所以整理成这个仓库。

## 一、本仓库现状

macOS 工具较全，Windows 和 Linux 目前只有烧录类示例，深度学习与机器人类工具还没有。

## 二、如何使用

| 想找什么 | 入口 |
|---|---|
| 🍎 macOS 上的工具 | [macos/](macos/README.md) |
| 🪟 Windows 上的工具 | [windows/](windows/README.md) |
| 🐧 Linux 上的工具 | [linux/](linux/README.md) |
| 按需求找一套工具（如「Mac 上复现树莓派类机器人项目」） | [recipes/](recipes/README.md) |
| 某个工具的详细说明、注意事项、替代品 | [tools/](tools/README.md) |

每个条目的「验证日期」是最近一次确认该工具仍然有效的日期。

## English summary

setup-cookbook is a community-maintained catalog of developer and everyday tools, organized by operating system (macOS, Windows, Linux). It also collects short "recipes" (tool sets for a given need) and write-ups such as flashing OS images from a Mac when the tutorial assumes Windows. The content is mostly in Chinese for now; English pull requests and issues are welcome. If a tool breaks or a link dies, please open an issue or PR. Installation and configuration guides are out of scope for now.
