# Mac 日常效率与多设备协作

> 把 Mac 用顺手，并在多台电脑、多块屏幕之间协作时的工具组合。

| 环节 | 工具 | 说明 |
|---|---|---|
| 看系统状态 | [Stats](../tools/stats.md)（🍎） | 菜单栏显示 CPU、内存、网络等 |
| 整理菜单栏 | [Dimble](../macos/efficiency.md)（🍎） | 隐藏不常用的菜单栏图标，需要 macOS 27 |
| 多显示器 | [DockAnchor](../tools/dockanchor.md)（🍎） | 把 Dock 固定在一块屏幕上 |
| 鼠标滚动方向 | [Scroll Reverser](../macos/efficiency.md)（🍎） | 鼠标与触控板分别设置 |
| 写 Markdown | [Typora](../macos/efficiency.md)（🍎🪟🐧）+ [PicGo](../macos/efficiency.md)（🍎🪟🐧） | 所见即所得写作，图片自动上传图床 |
| 多台电脑共用键鼠 | [Synergy](../macos/efficiency.md)（🍎🪟🐧） | 付费；注意各版本之间不互通，免费方案见系统页的注意事项 |
| 密码管理 | [Bitwarden](../macos/network-security.md)（🍎🪟🐧） | 开源，有永久免费档 |

## 注意

- 注意：Typora 与 Synergy 是付费软件，价格以各自官网为准。
- 作者曾用的启动器 Alfred，见 [效率与系统增强](../macos/efficiency.md)；它的核心功能免费，进阶功能付费。
