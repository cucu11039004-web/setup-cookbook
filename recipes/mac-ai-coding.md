# Mac 上的 AI 编程工具链

> 在 Mac 上同时使用 Claude Code、Codex 等命令行 AI 工具，并需要在多个服务商、多台服务器之间切换时的工具组合。

| 环节 | 工具 | 说明 |
|---|---|---|
| 终端 | [Warp](../tools/warp.md)（🍎🪟🐧） | 带 AI 助手的终端；也可以用系统自带终端或 iTerm2 |
| 切换服务商配置 | [CC Switch](../tools/cc-switch.md)（🍎🪟🐧） | 一处管理多个命令行工具的服务商，一键切换 |
| 另一个智能体环境 | [DeepSeek Harness](../macos/ai-remote.md)（🍎🪟🐧） | DeepSeek 开源的智能体运行环境，桌面应用目前是预览版 |
| 编辑器 | [Visual Studio Code](../macos/dev-basics.md)（🍎🪟🐧） | 日常编辑 |
| 连接远程服务器 | [FinalShell](../tools/finalshell.md)（🍎🪟🐧） | 图形化 SSH 与 SFTP |

## 注意

- 注意：AI 命令行工具和服务商的支持范围变化很快，以各自官方 README 为准。
- CC Switch 会管理各工具的配置文件，切换后需要重启对应命令行工具才生效（据第三方资料，Claude Code 除外）。
