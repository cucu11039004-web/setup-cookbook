## 表格列说明

> 每个分类页的表格用同一套列，新增条目时照此填写。

| 列 | 含义 |
|---|---|
| 工具 | 名称，链接到官网或官方仓库 |
| 平台 | 🍎 macOS、🪟 Windows、🐧 Linux，只写官方有版本的系统 |
| 用途 | 一句话；括号里放次要信息（如「作者曾用」） |
| 费用 | `免费开源`、`免费`、`免费增值`、`付费买断`、`订阅`、`待核实`；不写具体金额 |
| 验证 | `状态 · 日期`，状态为 `可用`、`停更`、`失效`、`待核实` |
| 详情 | 链接到 `tools/` 下的卡片；还没有卡片写 `—` |

「验证」列指最后一次核对官网链接、平台和费用的日期，不代表当天实机试用过。
