# FinalShell

> 国产的图形化 SSH 客户端，集成多标签终端、SFTP 文件管理、服务器资源监控，支持 Windows 远程桌面。

## 平台与费用

| 系统 | 支持情况 | 备注 |
|---|---|---|
| 🍎 macOS | 有 | 官网提供 Apple 芯片（M1/M2/M3）版和 Intel（x64）版，均为 .pkg |
| 🪟 Windows | 有 | x64 安装包（.exe） |
| 🐧 Linux | 有 | x64、Arm64，另有龙芯（LoongArch64）版，均为 .deb |

费用与许可：闭源软件；是否收费、哪些功能收费，以官网为准（本条目未核实）。

## 注意

- 注意：官网提醒不要使用修改版、破解版或补丁，可能造成信息泄露。
- 注意：搜索结果里有不少自称官网的站点（如 finalshell.net.cn），是否由开发者运营未核实，下载以 [hostbuf.com](https://www.hostbuf.com/) 为准。
