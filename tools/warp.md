# Warp

> 带 AI 助手的现代终端，用 Rust 编写，可在 macOS、Windows、Linux 上使用。

## 平台与费用

| 系统 | 支持情况 | 备注 |
|---|---|---|
| 🍎 macOS | 有 | 官网 Mac 页称个人使用免费 |
| 🪟 Windows | 有 | 据第三方评测：Windows 10、11，x64 与 ARM64 |
| 🐧 Linux | 有 | 据第三方评测：deb、rpm、Arch 和 AppImage |

费用与许可：有免费档和付费档，AI 额度的规则调整频繁，各来源说法不一，以 [官网定价页](https://www.warp.dev/pricing) 为准。据第三方资料，客户端源码自 2026 年 4 月起在 GitHub 公开（AGPL-3.0），以官方仓库说明为准。

## 注意

- 注意：Warp 与 Cloudflare 的 WARP（1.1.1.1 的 VPN 客户端）是两个不相关的产品，搜索时容易混淆。
- 平台要求与安装方式（如系统版本、包管理器命令）各来源不完全一致，下载前看 [官网下载页](https://www.warp.dev/download)。

## 替代品

| 替代品 | 区别 |
|---|---|
| [iTerm2](https://iterm2.com/) | 仅 macOS；成熟的终端模拟器，不以 AI 为卖点 |
| [Ghostty](https://ghostty.org/) | 偏性能与原生体验的终端 |
| [Alacritty](https://alacritty.org/) | 跨平台，极简，配置靠文件 |
