# DockAnchor

> 让 macOS 的 Dock 固定在一块屏幕上。多显示器时，鼠标靠近任一屏幕底部，Dock 就会跳过去，它用来阻止这种跳动。

## 平台与费用

| 系统 | 支持情况 | 备注 |
|---|---|---|
| 🍎 macOS | 有 | 原理是拦截鼠标事件，需要授予「辅助功能」权限，否则不起作用 |
| 🪟 Windows | 无 | |
| 🐧 Linux | 无 | |

费用与许可：免费，开源。可从 GitHub Releases 下载，也有 Homebrew cask `dockanchor`（据第三方资料，以官方 README 为准）。

功能：点选要固定的显示器；可按已连接的显示器自动切换配置（如办公室、家里）；固定的显示器被拔掉时自动回到主显示器；支持开机启动。

## 注意

- 注意：同名项目不止一个，包括 [Micropeptide/DockAnchor](https://github.com/Micropeptide/DockAnchor)（改为限制鼠标触到屏幕最下一行像素）和 [galacticdave/DockAnchor-2.0](https://github.com/galacticdave/DockAnchor-2.0)（派生版）。本卡片指 [bwya77/DockAnchor](https://github.com/bwya77/DockAnchor)，与作者本机安装的一致。
- 注意：没给辅助功能权限时，Dock 仍会在屏幕间跳动。
