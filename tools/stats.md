# Stats

> 在 macOS 菜单栏显示 CPU、GPU、内存、磁盘、网络、电池、传感器等系统状态的小工具。

## 平台与费用

| 系统 | 支持情况 | 备注 |
|---|---|---|
| 🍎 macOS | 有；官方 README 写 macOS 12（Monterey）及以上 | 只支持正式版系统，不支持 beta；更老的系统在 README 里有旧版链接 |
| 🪟 Windows | 无 | |
| 🐧 Linux | 无 | |

费用与许可：免费，MIT 开源。项目由个人维护，不接受外部贡献。

## 注意

- 注意：网上有不少基于它改的仓库和安装脚本，下载以 [exelban/stats](https://github.com/exelban/stats) 官方仓库为准。
