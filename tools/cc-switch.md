# CC Switch

> 一个桌面应用，集中管理 Claude Code、Codex、Gemini CLI 等 AI 编程工具的服务商（provider）配置，一键切换。

## 平台与费用

| 系统 | 支持情况 | 备注 |
|---|---|---|
| 🍎 macOS | 有 | 可用 Homebrew 安装：`brew tap farion1231/ccswitch` 后 `brew install --cask cc-switch`（据第三方资料） |
| 🪟 Windows | 有 | 安装包在 GitHub Releases |
| 🐧 Linux | 有 | 同上 |

费用与许可：免费，MIT 开源，基于 Tauri 2。

功能概览：服务商一键切换与托盘快速切换；MCP 与 Skills 的统一面板；提示词文件（CLAUDE.md、AGENTS.md、GEMINI.md）同步编辑；支持的工具数量随版本增加，具体列表看官方 README。

## 注意

- 注意：官方 README 声明唯一官网是 ccswitch.io，下载以官网和 [farion1231/cc-switch](https://github.com/farion1231/cc-switch) 为准，谨防仿冒站。
- 切换服务商后，需要重启终端或对应的命令行工具才生效（Claude Code 除外，据第三方资料）。
- 各版本支持的工具和功能变化较快（作者本机已是 4.x），以官方 README 和 Release 说明为准。
