# 工具卡片

> 一个工具一个文件，记录用途、各系统的支持情况、费用、注意事项和替代品。系统页（`macos/`、`windows/`、`linux/`）里的表格只是摘要，详细内容以卡片为准。

新增卡片请复制 [_template.md](_template.md)，并在下表加一行。表格里没有「详情」链接的工具，目前只有系统页里的一行摘要，欢迎补卡片。

注意：卡片里的「替代品」仅供参考，只有来自官网或官方说明的信息才会标明来源。
